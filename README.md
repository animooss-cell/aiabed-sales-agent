# راهنمای ایجنت فروش هوشمند aiabed.ir

این پروژه پیام‌های ورودی فرم «تماس با ما» وب‌سایت aiabed.ir را بررسی کرده و بر اساس کانال ترجیحی مشتری اقدام می‌کند:
- درخواست‌های تماس تلفنی: ثبت در `data/phone_calls_todo.json` برای تماس مستقیم خودتان
- درخواست‌های واتساپ: تولید لینک چت مستقیم همراه با متن پیش‌نویس آماده
- درخواست‌های تلگرام: تولید لینک مستقیم چت تلگرام

## نحوه اجرا
```powershell
python run.py
```
سپس از منوی عددی گزینه مورد نظر را انتخاب کنید.
